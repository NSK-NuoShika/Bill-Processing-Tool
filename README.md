# Bill-Processing-Tool

## 1. 项目介绍

Bill-Processing-Tool 是一个基于 Python 的桌面端账单处理工具，用于把不同来源的 Excel 账单合并为统一格式，并借助大语言模型自动完成账单分类，项目创造性使用系统 ID 对 API KEY 加密，避免因泄露造成损失。

### 技术栈
- Python 
- Tkinter：桌面图形界面
- openpyxl：Excel 读写
- OpenAI Python SDK：接入 OpenAI 兼容的 LLM API
- cryptography + py-machineid：使用系统唯一ID，加密保存 API Key

### 实现的功能

- 合并两个账单 Excel 文件，生成统一的 `总账单` 工作表
- 按用户配置的分类类别，由大模型为每笔账单分类
- 按分类生成独立工作表，并合并输出 Excel 文件
- 支持自定义 LLM 的 Base URL、API Key、模型和用户提示词

### 解决的痛点

不同支付平台、银行或业务系统导出的账单，表头结构、列顺序、收支表达方式往往不一致。手工把多份账单合并并逐条分类，既耗时又容易出错。

## 2. 使用方法

### 从源码运行

先从项目根目录的 requirements.txt 安装依赖：

```powershell
pip install -r requirements.txt
```

然后从项目根目录启动程序：

```powershell
python src/main.py
```

### 从可执行程序运行

下载 Release 发布的便携版，运行可执行程序即可。

### 界面操作

1. 在“配置”区域填写 `Base_Url`、`Key`、`Model`，并在“种类”中填写英文或中文分类，分类之间用英文逗号分隔。按需修改提示词后点击“提交配置”。
2. 在“账单 1”和“账单 2”中选择需要处理的 Excel 文件，填写内容。
3. 程序会在输出目录生成 `bill_<时间戳>.xlsx`。

### 使用注意事项

- 所有行列索引均起始于0：第 A 列是索引 0，第 1 行是索引 0，第 1 个工作表是索引 0。
- 由于不同账单对收入、支出、中性交易的表示不同，例如有的表示为（收入、/、支出），有的则是（收入、不计收支、支出），因此请在收支示例中填写该账单收支类型的取值，以便程序归一化。
- “首行索引”表示从哪一行开始读取数据，是第一条账单信息所在的行，而不是表头所在的行。
- 时间、交易方、商品、收付、金额列的索引按实际 Excel 列位置填写。
- 默认读取第一个 sheet，即索引为零的 Sheet，务必将待分类的 Sheet 放到最前面。
- 收支类型示例的填写顺序和归一化规则见上方“收支类型的三个取值”小节。
- 必须使用能够兼容 OpenAI Chat Completions 接口的 API。
- 程序内置对输出格式等要求的提示词，用户只需要输入个性化分类的提示词即可。
- 必须填满两个账单才能开始分类。

# 3. 项目展望

- 程序分类的速度受模型响应影响，速度仍然比较慢，后续将增加多线程调用。
- 程序固定使用两个账单，后期将优化为不定账单数量。
